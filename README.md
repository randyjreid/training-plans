# training-plans

An active training plan, published so automation can fetch it.

- **[`current-plan.md`](current-plan.md)** — the active plan. An
  automated assistant fetches it nightly via its raw GitHub URL on
  `main`, so it must always exist at the repo root with that exact
  filename.
- **[`archive/`](archive/)** — completed plans, filed by date range.

Automated edits to this repo are governed by
[`CLAUDE.md`](CLAUDE.md), which covers the file contract, privacy
rules, and plan content standards.
